REA 技能（手机 Claude Code 用）使用说明
=====================================

这是什么
--------
从 morluto/rea 官方仓库里扒出的正牌用户技能 reverse-engineer-anything
（SKILL.md + 6 份参考文档，版本 44），已按 Claude Code 认的目录摆好：
  .claude/skills/reverse-engineer-anything/...

它只是"技能说明"（怎么做调查的流程和取证纪律），不含 REA 的分析工具本体。
工具本体（MCP 服务）必须装在电脑上本地运行，手机云端会话装不了。

怎么用（3 步）
--------------
1. 在 GitHub 建一个空仓库（名字随意，比如 my-skills），不要勾选 README，保持空的。
2. 把仓库名告诉 Muse（就是我），我把 .claude 这一整套推上去，你不用手动传文件。
3. 手机打开 Claude App → Code 标签页 → 新建会话 → 选这个仓库 →
   在会话里输入 /reverse-engineer-anything，或者直接说
   "用 REA 的流程帮我拆解 XX 网站/功能"，技能即生效。

备注
----
- 想让某个具体项目（比如某个网站仓库）也带这个技能，把 .claude 文件夹
  放到那个仓库根目录即可，告诉我仓库名我来推。
- 技能教的流程（定目标→拆解取证→标注未知→重建→对照验证）在手机上就能用，
  拆网站、读代码这类活照常干；
  真正调用 REA 工具拆二进制、APK、本地 App 的活，需要 Mac 上装好 REA 本体
  （npx rea-agents setup，需先装 Node.js），那是另一条线。
